# AI Tells Blacklist & Korean Conversion Polish

Clients and readers distrust copy the moment it reads machine-generated. Remove structural AI shapes first — swapping single adjectives while keeping AI rhythm still reads as AI.

## 1. Structural AI Tells (Hard Bans)

| Pattern | Banned Shape (EN / KR) | Fix Rule |
| :--- | :--- | :--- |
| **Contrast Reveal** | `"It's not X, it's Y."`, `"Not because X. Because Y."` / `"단순한 X가 아닙니다. Y입니다."`, `"X가 아니라 Y입니다."` | State Y directly with the concrete reason. |
| **3-Item Negation List** | `"No setup, no templates, no waiting."` / `"복잡한 설정 없이, 기다림 없이, 실패 없이."` | Say what actually happens instead. Put a true absence once near the CTA (`"로그인 없이 바로 시작"`). |
| **Trailing Comma Pile-On** | `"Generates plans automatically, no spreadsheets, boosting ROI, unlocking speed."` / `"~해주며, ~하고, 더 나아가 ~까지 지원합니다."` | End the sentence cleanly at the main claim. Split distinct facts into short sentences. |
| **Self-Answered Drama** | `"The result? 3x faster."`, `"One word: speed."` / `"그 결과는? 놀라웠습니다."`, `"핵심은 하나입니다: 속도."` | Delete the throat-clearing question/colon and state the fact directly. |
| **Reflexive Rule of Three** | Stacking 3 adjectives/bullets everywhere (`"Fast, smart, scalable"`, `"정확하고, 빠르고, 체계적인"`) | Use 1, 2, or 4 specifics earned by actual facts. |
| **Hollow Stock Openers / Closers** | `"In today's fast-paced world"`, `"Whether you're X or Y"`, `"급변하는 K-뷰티 시장에서"`, `"이제 ~의 시대가 열렸습니다"`, `"지금 바로 혁신을 경험하세요"` | Open with the user's concrete friction; end on the outcome or CTA. |
| **Overused Em-Dashes** | Multiple `—` breaks in heroes, ads, or social posts | Use commas, periods, or line breaks cleanly. |

## 2. Korean B2B / K-Beauty Cliché Blacklist
Remove immediately unless quoting a verified review:
- **Buzzwords**: `"혁신적인"`, `"게임체인저"`, `"압도적인"`, `"올인원"`, `"원스톱"`, `"고도화"`, `"패러다임 전환"`, `"초개인화"`, `"시너지"`, `"솔루션 제공"`
- **Passive Translationese**: `"~되어집니다"`, `"~할 수 있게 해줍니다"`, `"~하는 데 도움을 줍니다"`, `"~의 제공을 통해"` → rewrite to **active user/product verbs** (`"1분 만에 뽑습니다"`, `"바로 연결합니다"`).
- **Abstract Subjects**: `"본 플랫폼은 마케터의 역량을 극대화..."` → make the reader the subject (`"오늘 아침 터진 쇼츠로 우리 제품 기획안을 씁니다"`).
- **Internal Jargon Leak**: Never leak developer/internal labels (`스냅샷`, `파이프라인`, `Go/Pivot/Drop`, `LLM`, `프롬프트`) into customer-facing copy.

## 3. Headline Formulas Built on Real Proof
Use formulas as scaffolding, then swap every placeholder with concrete, falsifiable facts:
- **Outcome without Pain**: `"{특정 작업} 없이 {원하는 결과} 끝내기"` (only 1 negation, tied to a real chore).
- **Audience + Job**: `"{구체적 대상}이 {구체적 상황}에 바로 쓰는 {도구 성격}"`.
- **Category Contrast (Plain Fact)**: `"{기존 낡은 대안} 대신, {실제 데이터/방식}으로 {결과}"`.
- **De-hyped Proof Lead**: `"{검증 가능한 숫자/출신 맥락} 기반 {실무 결과}"` (never round up or pad stats).

## 4. Pre-Delivery Self-Check
1. Search draft for `"아니라"`, `"없이"`, `"혁신"`, `"게임체인저"`, `"뿐만 아니라"`, self-answered `?`, and stacked `—`.
2. Read every sentence > 20 English words or > 45 Korean characters aloud — split or cut dead weight.
3. Verify zero unverified numbers/claims; flag missing proof with `[NEED: ...]`.
4. Check alignment with `.agents/brand-context.md` (and `AGENTS.md` / `docs/POLICY.md` if present).
