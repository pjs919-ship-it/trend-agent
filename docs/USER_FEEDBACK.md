# 트렌드핏 (TrendFit) 유저 피드백 · 개선 루프

> **목적**: 실제 사용자(마케터)가 겪은 불편을 **원문 → 진짜 원인 → 개선 결정 → 검증 잠금** 4단계로 기록해, 감이 아니라 근거 기반으로 제품과 마켓핏을 반복 개선한다.

---

## 유저 피드백 처리 루프 (4단계)

1. **원문 기록**: 사용자의 말과 막힌 지점을 가공 없이 그대로 적는다.
2. **근본 원인 진단**: "설명을 안 읽어서"로 넘기지 않고 **첫 시선(10초 내 행동 예측)·정보 위계·단어 직관성** 중 무엇이 문제였는지 짚는다.
3. **최소 해법 설계 (Ponytail 원칙)**: 안내 문구를 덧붙이기 전에 **혼동을 주는 요소부터 빼고**, 시선 순서에 맞게 재배치한다.
4. **반영 & 재발 방지**: 화면 수정 후 `qa/eval_golden.py`에 금지/필수 UI 문구 체크를 추가해 회귀를 막고, 커밋 해시로 반영 이력을 남긴다.

---
