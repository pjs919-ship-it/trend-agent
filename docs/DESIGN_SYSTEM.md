# 🎨 Design System v2: K-Beauty TrendSetter Pro (B2B Edition)

> **버전**: v2.0 (Sprint 4 B2B 의사결정 대시보드 표준)  
> **타깃 페르소나**: K-뷰티 화장품 브랜드사 인하우스 마케터 (예: 더랩바이블랑두 담당자)  
> **핵심 목표**: 월요일 아침 **10분 안에** "오늘 올라탈 트렌드(Go)"와 "버릴 트렌드(Drop)"를 냉정하게 판단하고, **팀장 보고서와 인플루언서 DM을 원클릭 복사**해 즉시 실행할 수 있는 **극강의 정보 위계(Scannability)**와 **증거 기반 신뢰(Evidence-First Trust)** 구현.

## 1. 디자인 철학 & 시각적 계승 원칙

### 1.1 3대 B2B 설계 원칙
1. **3-Second Scannability (3초 의사결정 스캔)**
   - 대시보드를 열자마자 최상단 요약 바에서 오늘 클리핑 수량·상승속도·Go/Pivot/Drop 비율을 3초 안에 파악한다.
   - 모든 수치 지표에는 `font-variant-numeric: tabular-nums`를 적용해 자리수 정렬을 유지한다.
2. **Evidence-First & Zero-Hiding (근거 직결 · 경고 숨김 금지)**
   - 마케터가 유튜브를 따로 켜지 않아도 **실제 자막 원문 인용(`"..."`) + 1:1 영상 썸네일 스트립**으로 10초 만에 팩트를 검증한다.
   - **자막 미확인(`text_source="meta"`)**, **검수 필요(`needs_review=True`)**, **제품 신뢰도 요약 기반(`confidence!="high"`)** 등 리스크는 절대 숨기지 않고 전용 경고 뱃지/배너로 전면 노출한다.
3. **One-Click Actionability (즉시 업무 대체)**
   - 읽고 끝나는 리포트가 아니라, Go 카드 하단에서 `[📋 팀장/슬랙 보고 복사]`와 `[💌 인플루언서 DM 복사]` 2종 버튼으로 즉시 발송한다.

### 1.2 레거시(`TrendSetter_Agent (1).html`) 시각 자산 계승 및 고도화
| 시각 요소 | v1 계승 자산 | v2 B2B 고도화 |
|---|---|---|
| **인사이트 박스** | 좌측 퍼플 액센트 + 그라데이션 박스 | 브랜드 편향 0% **시장 관통 패턴 2~3개 넘버링 박스** (P1) |
| **도트 게이지** | 우측 상단 `●●●●○ 4점` | Go/Pivot/Drop 판정 컬러와 동기화 + `👑 TOP GO PICK` 골드 강조 |
| **1:1 근거 영상 스트립** | 썸네일 + 제목 + 조회수 + 날짜 | **일평균 조회수 🔥(`views_per_day`) + 좋아요율(%)** 추가 및 자막 검증 상태 직결 |
| **골드 하이라이트** | `2px solid #BF8A12` + `#fffdf6` | 전체 Go 중 최우선 1순위(`5점` 또는 최고 일평균 조회수) 카드에 적용 |
| **Drop/원본 처리** | 없음 (전부 평면 나열) | **Drop 기본 접힘(`<details>`) + 탈락 사유 투명 공개**, P0 Top 10 정렬 뷰 추가 |

### 2.2 타이포그래피 & 수치 규격
- **Font Family**: `-apple-system, BlinkMacSystemFont, "Pretendard", "Apple SD Gothic Neo", "Malgun Gothic", "Segoe UI", sans-serif`
- **수치 정렬**: 모든 조회수·일평균·좋아요율·점수에 `font-variant-numeric: tabular-nums;` 필수 적용.

| 레벨 | 크기 / 굵기 / 행간 | 용도 |
|---|---|---|
| **Hero Title** | `1.85rem (29.6px)` / `800` / `1.25` | 대시보드 상단 서비스 타이틀 |
| **KPI Metric Value** | `1.5rem (24px)` / `800` / `1.2` | Executive Summary Strip 핵심 숫자 |
| **Section Heading** | `1.15rem (18.4px)` / `800` / `1.35` | P1/P2/P3/P0 섹션 헤더 |
| **Card Title** | `1.12rem (18px)` / `800` / `1.35` | Go 캠페인 카드 제목 |
| **Body / Storyboard** | `0.92rem (14.7px)` / `400~500` / `1.55` | 콘티 설명, 판정 근거, 시장 패턴 |
| **Quote Text** | `0.9rem (14.4px)` / `600` / `1.5` | 실제 자막 원문 인용 (`"..."`) |
| **Meta / Badge** | `0.78rem (12.5px)` / `700` / `1.3` | 뱃지, 영상 메타, 테이블 보조 정보 |

### 2.3 간격 · 라운딩 · 그림자 · 브레이크포인트
- **Max Container Width**: `1080px` (HTML Standalone) / Streamlit `layout="wide"` 내부 `max-width: 1120px` 정렬 권장.
- **Border Radius**: 메인 카드 `16px` · 중첩 컨테이너(콘티/근거) `12px` · 스텝/버튼 `10px` · 뱃지/칩 `999px` · 썸네일 `6px`.
- **Elevation**: 기본 카드 `0 1px 3px rgba(28, 23, 48, 0.05)` / 호버 `0 6px 16px rgba(28, 23, 48, 0.07)`.
- **Responsive Breakpoints**:
  - Desktop (`≥ 900px`): Executive Summary 4~5열 그리드, 4단 콘티 2x2 그리드, 복사 버튼 가로 2열.
  - Tablet/Mobile (`< 768px`): Executive Summary 2열 그리드, 4단 콘티 1열 스택, 복사 버튼 세로 스택.

## 4. 신뢰·경고 뱃지 규격 (Trust & Risk Badge Spec)

B2B 마케터의 법무·브랜드 리스크를 막기 위해 `pipeline.py`의 감사 필드를 아래 시각 규격과 **1:1 강제 매핑**한다.

| 조건 (`pipeline.py` 필드) | 뱃지 / 배너 UI 텍스트 | 스타일 토큰 | 노출 위치 | 필수 규칙 |
|---|---|---|---|---|
| `text_source == "caption"` & `evidence_ok == True` | `✅ 자막 검증 완료` | `--go` / `--go-soft` | Go/Pivot 카드 헤더, Top 10 테이블 | 인용문 박스와 함께 신뢰도 보증 |
| `text_source == "meta"` | `⚠️ 자막 미확인 (직접 시청 필요)` | `--warn` / `--warn-soft` + `1px solid #F59E0B` | Pivot 카드 헤더 최전면, Top 10 테이블 | 코드 가드레일상 Go 자동 차단(Pivot 상한). 절대 숨김 금지 |
| `evidence_ok == False` | `🚫 근거 검증 실패 (자동 제외)` | `--drop` / `--drop-soft` | Drop 접힘 목록 | 합계 정합성 유지를 위해 증발 금지, Drop 목록에 명시 |
| `needs_review == True` | `🚨 발송 보류 — 검수 필요: {violations}` | `--danger` / `--danger-soft` + `border-left: 4px solid #B91C1C` | Go 카드 콘티 최상단 배너 + 복사 버튼 경고 상태 | DM 복사 버튼 라벨을 `⚠️ 검수 후 DM 복사`로 변경해 오발송 차단 |
| `product_confidence != "high"` | `⚠️ [제품 정보 확인 필요] 요약 기반({confidence}) — 최종 집행 전 공식 상세 원문 확인` | `--warn` / `--warn-soft` | 대시보드 최상단 전역 알림 바 | 인플루언서 DM 복사 본문에는 **절대 포함하지 않음** (마케터 UI/내부 보고 전용) |
| `low_views_fallback == True` | `ℹ️ 저유입 기준 완화 포함 (최소 조회수 미달 영상 일부 포함)` | `--muted` / `--drop-soft` | Executive Summary Strip 보조 주석 | 수집 영상 부족 시 투명 고지 |

### 4.1 판정 뱃지 & 도트 게이지 규칙
- **Go (4~5점)**:
  - `score == 5` (또는 최상위 1순위 Go): `👑 TOP GO PICK` + `🎯 Go` + `●●●●● 5점` (`color: var(--gold)`) + 카드 `.tcard.gold`.
  - `score == 4`: `🎯 Go` + `●●●●○ 4점` (`color: var(--go)`).
- **Pivot (3점)**: `⚠️ Pivot` + `●●●○○ 3점` (`color: var(--warn)`).
- **Drop (1~2점)**: `❌ Drop` + `●○○○○ 1점` 또는 `●●○○○ 2점` (`color: var(--drop)`).

## 5. 섹션별 상세 컴포넌트 규격

### 5.1 [최상단] 의사결정 요약 바 (Executive Summary Strip)
- **구성**: 4개 KPI 타일 가로 배치 (`grid-template-columns: repeat(4, 1fr)`).
  1. **클리핑 쇼츠**: `{stats.videos}건` / 서브: `자막 확보 {stats.transcript_caption}건 ({caption_pct}%)`
  2. **평균 조회수**: `{avg_views:,}회` / 서브: `평균 좋아요율 {avg_like_rate:.2f}%`
  3. **최고 상승속도 🔥**: `{max_vpd:,}회/일` / 서브: `최근 {days_range}일 기준 급상승 1위`
  4. **판정 분포**: 3색 인라인 필 `🎯 Go {go}` · `⚠️ Pivot {pivot}` · `❌ Drop {drop}` / 서브: `합계 {go+pivot+drop}건 정합`
- **시각 규격**: 배경 `#FFFFFF`, 테두리 `1px solid var(--line)`, 라운딩 `14px`, 패딩 `14px 16px`.

### 5.2 [P1] 시장 관통 패턴 박스 (Market Patterns Box)
- **클래스**: `.insight-box`
- **스타일**: `background: linear-gradient(135deg, #F6F2FF 0%, #FFFFFF 100%)`, `border: 1px solid #E0D8F5`, `border-left: 5px solid var(--purple)`, `border-radius: 14px`, `padding: 18px 22px`.
- **콘텐츠**:
  - 헤더: `🧭 이번 주 K-뷰티 시장 관통 패턴` + 우측 보조 태그 `브랜드 편향 0% · 실제 자막 기반`
  - 리스트: `market_patterns` 2~3개를 번호 원형 배지(`1`, `2`, `3`)와 함께 간결하게 출력.

### 5.3 [P2 + P3] Go 판정 캠페인 카드 (`.tcard` / `.tcard.gold`)
1. **헤더 행 (Flex Space-Between)**:
   - 좌측: `[👑 TOP GO PICK (조건부)]` `[🎯 Go]` `[{format_tag}]` `[✅ 자막 검증 완료]`
   - 우측: 도트 게이지 `●●●●● 5점`
2. **검수 경고 배너 (조건부 `needs_review == True`)**:
   - 빨간 배경(`--danger-soft`), 좌측 4px 보더(`--danger`), 위반 사유(`violations`) 전체 나열.
3. **핵심 요약 & 근거**:
   - 카드 제목: 영상 기반 캠페인 컨셉명 또는 영상 제목.
   - `Go 판정 근거`: `judgement.reason` (1~2문장).
   - `연결 공식 문구`: `🔗 {judgement.linked_claim}` (틸 소프트 칩).
4. **실제 자막 원문 인용 박스 (`.quote-box`)**:
   - 스타일: `background: #F4FBF9`, `border-left: 3px solid var(--go)`, `border-radius: 8px`, `padding: 10px 14px`.
   - 라벨: `💬 실제 영상 자막 원문 인용` (우측 `100% 원문 대조 통과`)
   - 본문: `"{hook_quote || evidence_quote}"`
5. **1:1 직결 근거 영상 스트립 (`.evid-item`)**:
   - 좌측: `96x54px` 16:9 썸네일 (`object-fit: cover; border-radius: 6px`).
   - 중앙: 영상 제목(1~2줄 말줄임) + 메타 1줄: `📺 {channel_title} · 👀 {views:,}회 · ` **`🔥 {views_per_day:,}회/일`** ` · ❤️ {like_rate:.2f}% · 📅 {published_at[:10]}`.
   - 우측: `쇼츠 보기 ↗` 아웃라인 버튼 (`https://youtube.com/shorts/{video_id}`, `target="_blank"`).
6. **4단 숏폼 콘티 (`.storyboard-box`)**:
   - 2x2 CSS Grid (`gap: 10px`), 각 스텝 카드 내부:
     - `⚡ 1. 첫 3초 훅` (`brief.hook`)
     - `👀 2. 비포 공감 상황` (`brief.before`)
     - `💧 3. 제품 침투 시점` (`brief.product_moment`)
     - `🛒 4. 구매/참여 CTA` (`brief.cta`)
   - 하단 주의사항 스트립: `📝 크리에이터 주의사항: {brief.creator_note}` + `🚫 절대 금지 표현: {banned_list}` (연한 레드/그레이 보조 바).
7. **원클릭 복사 2종 액션 바 (`.action-bar`)**:
   - 좌측 버튼 (Secondary Purple): `📋 팀장/슬랙 보고 복사` — 전체 또는 해당 컨셉의 `internal_report_md` 복사.
   - 우측 버튼 (Primary Purple, `needs_review=True` 시 Danger Outline): `💌 인플루언서 DM 복사 (깨끗한 본문)` — 내부 출처 주석(`(kurly, glowpick 요약)` 등)·개발자 용어·내부 경고가 제거된 **즉시 대외 발송 가능 본문** 복사.
   - 클릭 피드백: 2초간 `✅ 클립보드에 복사되었습니다!` 토스트/버튼 상태 전환.
8. **Empty State (Go == 0건)**:
   - 중립 점선 카드(`border: 1px dashed var(--line-strong)`): `"이번 수집 배치에서는 우리 제품과 억지 연결 없이 바로 집행할 Go 컨셉이 없습니다. 아래 Pivot 후보를 직접 시청해 검토하거나 수집 기간을 조정해 보세요."`

### 5.4 [P2] Pivot & Drop 영역
- **Pivot 섹션 (`⚠️ Pivot — 서브 테스트 / 직접 시청 검토`)**:
  - 컴팩트 수평 카드(콘티 없음).
  - 구성: 썸네일(`72x40px`) + `[⚠️ 자막 미확인 (직접 시청 필요)]`(meta인 경우 최앞단) + `[{format_tag}]` + `●●●○○ 3점` + 제목(쇼츠 링크) + 지표(`조회수 · 일평균🔥`) + `Pivot 사유(reason)`.
- **Drop 섹션 (`❌ Drop — 부적합 탈락`)**:
  - **기본 상태: 접힘** (HTML `<details>`, Streamlit `st.expander(..., expanded=False)`).
  - 요약 헤더: `❌ 부적합 탈락 {N}건 — 억지 연결 차단 내역 보기 (클릭하여 탈락 사유 확인)`.
  - 펼침 내부: 컴팩트 테이블/리스트 — `[도메인 뱃지]` | `영상 제목 (쇼츠 링크)` | `조회수` | **`탈락 사유(reason)`** (예: *"색조/메이크업 영역으로 기초 토너와 무관"*).

### 5.5 [P0] 클리핑 원본 Top 10 뷰 (접힘/탭)
- **기본 위치**: 페이지 최하단 (또는 상단 탭 전환 `📊 의사결정 대시보드` | `🎬 클리핑 원본 Top 10` | `📄 전체 복사 센터`).
- **정렬 컨트롤**: `[🔥 일평균 조회수순 (기본)]` · `[👀 총 조회수순]` · `[❤️ 좋아요율순]`.
- **컬럼 규격**:
  - `순위` | `영상(썸네일+제목 링크)` | `채널` | `총 조회수` | `일평균🔥` | `좋아요율` | `업로드일` | `자막` (`✅`/`⚠️`) | `포맷` | `판정` (`Go`/`Pivot`/`Drop`).

## 6. 듀얼 플랫폼 구현 명세 (Streamlit + Standalone HTML)

`pipeline.py`의 `run_pipeline()` 반환 JSON(`product`, `report_date`, `days_range`, `videos`, `facts`, `market_patterns`, `judgements`, `briefs`, `stats`, `product_confidence`, `internal_report_md`, `creator_guide_md`)을 **단일 데이터 계약(Single Data Contract)**으로 사용한다.

### 6.1 Streamlit (`app.py`) 구현 명세
1. **파이프라인 전환**: 기존 `agent_core.TrendReport` 단일 LLM 호출을 **`pipeline.run_pipeline()`**으로 교체하여 4단계 감사 + `internal_report_md`/`creator_guide_md`를 그대로 렌더링한다.
2. **레이아웃 구성**:
   - 상단 탭 2개 또는 수직 5단 구성:
     - **메인 뷰**: `[전역 신뢰도 배너]` → `[Executive Summary Strip (HTML 4열 그리드)]` → `[P1 Market Patterns Box]` → `[P2+P3 Go 카드 루프]` → `[P2 Pivot 컴팩트 리스트]` → `[st.expander("❌ Drop 부적합 탈락 N건", expanded=False)]` → `[st.expander("📊 클리핑 원본 Top 10 전체 보기", expanded=False)]`.
3. **원클릭 복사 2종 구현 (Streamlit 제약 대응)**:
   - Streamlit은 기본 버튼에 클립보드 API가 없으므로 다음 **이중 안전 패턴**을 적용한다:
     - **1차 (원클릭 버튼)**: `streamlit.components.v1.html()`로 경량 JS 복사 버튼 2종(`navigator.clipboard.writeText(...)` + `"✅ 복사 완료"` 피드백)을 Go 카드 하단에 인라인 배치.
     - **2차 (폴백/미리보기)**: Go 카드 하단 또는 상단 `📄 보고서/DM 전문 미리보기` expander 안에 `st.code(md_text, language="markdown")`(우측 상단 기본 복사 아이콘 제공) + `st.download_button(".md 저장")` 병행 제공.
4. **Top 10 정렬**: `st.radio("정렬 기준", ["🔥 일평균 조회수순", "👀 총 조회수순", "❤️ 좋아요율순"], horizontal=True)`로 `videos` 리스트를 정렬 후 HTML 테이블 또는 `st.dataframe(..., column_config={"url": st.column_config.LinkColumn(...)})`로 표시.
5. **보안/XSS 방어**: 모든 외부 유튜브 제목·채널명·인용문을 HTML 삽입 전 `html.escape()` 처리 필수.

### 6.2 Standalone HTML (`TrendSetter_KBeauty_Pro.html`) 구현 명세
1. **CSS 토큰 동기화**: `:root`에 섹션 2.1의 `--go`, `--warn`, `--drop`, `--danger`, `--hot` 토큰 추가.
2. **접힘 구조**: Drop 섹션과 P0 Top 10 원본 뷰는 네이티브 `<details class="b2b-details"><summary>...</summary>...</details>` 사용 (추가 JS 라이브러리 불필요).
3. **원클릭 복사 UX**:
   - `navigator.clipboard.writeText(text)` 실행 후 버튼 텍스트를 2초간 `✅ 복사 완료!`로 변경하고 하단 고정 토스트(`.toast`) 표시.
   - `needs_review === true`인 Go 카드의 DM 복사 버튼 클릭 시 `confirm("검수 필요 항목이 포함되어 있습니다. 내용을 확인 후 복사할까요?")` 1회 안전 확인.
4. **정렬 컨트롤**: P0 Top 10 영역 상단에 세그먼트 버튼(`.sort-btn.active`) 배치하여 `views_per_day` / `views` / `like_rate` 기준 클라이언트 즉시 재정렬.
5. **로컬 JSON 결과 뷰어 모드 (권장)**: API 키 직접 실행 외에 `pipeline.py` 실행 결과(`qa/run_latest.json`)를 드래그&드롭 또는 파일 업로드로 즉시 렌더링할 수 있는 로더를 제공하면 데모·검수 효율이 극대화된다.

## 7. Sprint 4 디자인 검수 체크리스트 (Design QA Gate)

UI 구현 완료 후 아래 8개 항목을 모두 통과해야 디자인 검수 PASS로 인정한다.

- [ ] **3초 스캔**: 스크롤 없이 첫 화면(Above-the-Fold)에서 Executive Summary Strip(클리핑 수, 평균 조회수, 최고 일평균🔥, Go/Pivot/Drop 분포)이 한눈에 보이는가?
- [ ] **P1 패턴 독립성**: Market Patterns Box가 개별 영상 요약 나열이 아니라 2~3개 관통 패턴으로 표시되는가?
- [ ] **Go 카드 팩트 직결**: 모든 Go 카드에 `도트 게이지`, `포맷 태그`, `✅ 자막 검증 완료`, `실제 자막 원문 인용 박스`, `1:1 썸네일+일평균🔥 스트립`, `4단 콘티`가 누락 없이 렌더링되는가?
- [ ] **경고 비은닉**: `text_source="meta"` 영상에 `⚠️ 자막 미확인 (직접 시청 필요)` 뱃지가, `needs_review=True` 브리프에 `🚨 발송 보류 — 검수 필요` 빨간 배너가 숨김 없이 표시되는가?
- [ ] **2종 복사 청결성**: `[💌 인플루언서 DM 복사]` 결과물에 내부 출처 주석(`kurly, glowpick 요약`), `products.json`, 마케터 내부 확인 배너가 0건 포함되는가?
- [ ] **Drop 투명 접힘**: Drop 항목이 기본 접힘 상태이며, 펼쳤을 때 탈락 사유와 원본 쇼츠 링크가 명확히 표시되는가?
- [ ] **P0 원본 탐색**: Top 10 전체 영상이 일평균 조회수순/총조회수순으로 정렬 가능하며, 판정 합계(`Go + Pivot + Drop`)가 총 클리핑 수와 100% 일치하는가?
- [ ] **XSS 및 반응형**: 영상 제목/자막의 특수문자(`<`, `>`, `"`)가 이스케이프되어 레이아웃이 깨지지 않으며, 768px 이하 화면에서 콘티와 KPI 타일이 깨지지 않고 재배치되는가?
