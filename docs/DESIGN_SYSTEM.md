# 🎨 Design System: K-Beauty TrendSetter Pro

---

## 1. 디자인 철학 (Design Philosophy)
> **"5초 안에 핵심 트렌드를 읽고, 1분 안에 우리 브랜드 캠페인을 결정한다."**

- **Scannability (스캔 편의성)**: 텍스트 덩어리를 없애고, 시선이 위에서 아래로 물 흐르듯 떨어지는 계층 구조.
- **Evidence-First (근거 우선주의)**: 모든 트렌드 카드는 근거 유튜브 영상 썸네일과 1:1로 결합되어 신뢰감을 부여.
- **K-Beauty Aesthetic (뷰티 전문 톤앤매너)**: 신뢰를 주는 딥 퍼플과 활력을 주는 골드/틸 컬러 악센트.

## 3. 정보 위계 (Information Hierarchy: 5-Stage Funnel)

```
[1단계] 🧭 시장 인사이트 (Market Insight Box)
       - 최상단 배치: 오늘 K-뷰티 쇼츠 시장 전체를 관통하는 2~3줄 요약

[2단계] 🗂️ 트렌드 카드 (Trend Cards: 3~5개)
       - 우측 상단: 브랜드 기회 점수 도트 게이지 (●●●●○ 4점)
       - 좌측 상단: 카테고리 뱃지 (루틴 / 챌린지 / 성분제형 / 리뷰)
       - 타이틀 + 30자 요약
       - 핵심 메타: [점수 근거] · [핵심 타깃] · [해시태그 칩]
       - 핵심 실행점: 💡 [캠페인 방향 1~2문장]

[3단계] 📌 직결 근거 영상 임베드 (Evidence Strip)
       - 카드 바로 아래에 실제 수집된 쇼츠 썸네일(16:9), 제목, 채널, 조회수, 날짜 1:1 매칭
       - 클릭 시 실제 유튜브 쇼츠 새 탭 재생

[4단계] 👑 GOLDEN PICK 카드 (골드 하이라이트)
       - 2px 골드 테두리 + 연한 골드 배경
       - 마켓 타이밍을 놓치면 안 되는 1등 추천 트렌드와 선정 이유

[5단계] 🏢 더랩바이블랑두 1클릭 프리셋 & 4단 숏폼 콘티
       - [딥 토너] [2.5 패드] [워터리 마스크] 원클릭 선택
       - [첫 3초 훅] - [연출 비포/애프터] - [제품 소구점] - [CTA] 스토리보드 카드
```

## 4. 컴포넌트 규격
* **트렌드 카드 (`.tcard`)**: `border-radius: 14px`, `border: 1px solid var(--line)`, `padding: 18px 20px`
* **점수 도트 (`.score`)**: `●` 채움 + `○` 비움 5단계 시각화
* **해시태그 칩 (`.chip`)**: `border-radius: 999px`, 배경 `#e7f4f2`, 텍스트 `#14897F`
* **영상 에비던스 박스 (`.evid`)**: 좌측 88x50px 썸네일 + 우측 텍스트 2줄 말줄임 처리
