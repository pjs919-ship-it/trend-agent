### 전환율 극대화를 위한 4가지 설계 원칙
1. **샘플 구경은 횟수 차감 제외**: 미리 채워진 예시(`속수분 토너`, `립틴트`)는 무제한 체험을 허용하고, **자기 브랜드/제품명을 직접 입력해 생성할 때만 1회 무료를 소진**시켜 억울한 이탈을 방지한다.
2. **몰아쓰기 수요 포착**: 마케터는 신상 오픈·캠페인 전날 하루에 4~6개 버전을 한꺼번에 뽑는 패턴이 잦다. 일 2회 무료는 일상 습관화에는 충분하면서, 실무 몰아쓰기 시점에 자연스러운 유료 결제 트리거가 된다.
3. **2단계 결과 하단 '시딩 추천 맛보기(Lock)'**: 기획안 생성 직후 하단에 "이 콘셉트와 톤이 맞는 마이크로 크리에이터 5명" 중 **1~2명만 실데이터로 노출**하고 나머지 3명과 맞춤 DM 생성은 잠금 처리해 `기획 → 시딩` 업셀 연결을 만든다.
4. **"일반 GPT/클로드와의 차별화" = 브랜드 컨텍스트 + 법무 가드레일**:
   - 단순 프롬프트 대신 ① **방금 뜬 K-뷰티 쇼츠 훅·지표 자동 주입**, ② **화장품법 제13조 과대광고 자동 검수**, ③ **내 브랜드 말투·금지어 저장(이혜원님 워크플로우 내장)** 으로 "일반 챗봇보다 빠르고 안전한 전용 툴" 포지션을 고정한다.

## 2. LLM 유료 모델 선택 & 비용 시뮬레이션

### 1회 기획안 생성 기준 토큰 가정
- 현재 `api/plan.js` 기준 프롬프트 상한 `16,000자`
- **입력(Input)**: 시스템 지시 + 영상 메타/요약 + 제품 정보 + JSON 스키마 ≈ **평균 3,500 토큰**
- **출력(Output)**: 카피 3종 + 4단 콘티 + 시딩 가이드 + 법무 체크 JSON ≈ **평균 1,500 토큰**
- *기준 환율*: `1 USD = 1,400 KRW` (2025~2026 표준 API 종량제 단가 기준)

### 추천 하이브리드 모델 라우팅
- **비회원 1회 + 무료 회원(일 2회)**: **`Gemini 2.5 Flash`**
  - 1회 약 6.7원으로, 무료 유저 트래픽이 늘어나도 원가 방어가 가능.
- **유료 회원(Pro, 월 29,000원 기준)**: **`Claude Sonnet 4.5`** (또는 `Gemini 2.5 Pro`)
  - 유료 고객 1명이 한 달에 **100회**를 생성해도 AI API 원가는 **약 2,700~4,600원(매출 총이익률 84~90%)**.
- **품질 핵심**: 모델 업그레이드와 함께 **브랜드 말투 예시(Few-shot 2~3개) 저장 기능**을 결합해야 "챗GPT 복붙보다 낫다"는 체감 품질이 완성된다.
