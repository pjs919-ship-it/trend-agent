# 📄 PRD: K-Beauty TrendSetter Pro (v1.0)
> **K-뷰티 인하우스 마케터를 위한 실시간 메가 트렌드 숏폼 캠페인 기획 및 환각 검증 솔루션**

---

## 1. 배경 및 문제 정의 (Problem Statement)
* **시장 문제**: K-뷰티 숏폼 시장(유튜브 쇼츠, 틱톡, 릴스)은 유행 주기가 3~7일로 극도로 짧음.
* **마케터의 페인 포인트**:
  1. **스크린타임 낭비**: 매일 아침 수작업으로 쇼츠를 보며 1~2시간씩 낭비하지만, 정작 바이럴 핵심 공식을 체계화하기 어려움.
  2. **저유입 잡음(Noise) 검색**: 단순 키워드 검색 시 조회수 1,000회 이하의 비인기 영상이 섞여 나와 진짜 대세 트렌드를 놓침.
  3. **우리 브랜드와의 결합 부재**: 트렌드를 봐도 "우리 제품(예: 더랩바이블랑두 딥 토너/패드)"에 어떻게 녹여야 할지 콘티 기획 단계에서 병목 발생.
  4. **AI 환각 위험**: 기존 AI 툴이 지어낸 가짜 트렌드나 존재하지 않는 레퍼런스를 믿고 캠페인을 기획했다가 리스크 발생.

---

## 2. 타겟 페르소나 (Target Persona)
* **메인 타겟**: **K-뷰티 인하우스 브랜드 마케터 (In-House Brand Marketer)**
* **대표 케이스**: **더랩바이블랑두 (THE LAB by blanc doux)** 마케팅 담당자
  * *핵심 고민*: "이번 주 올리브영 세일 / 환절기 시즌에 맞춰 우리 시그니처 3대 제품을 띄워야 하는데, 지금 유튜브에서 조회수 수십만 회 터지고 있는 숏폼 문법과 어떻게 엮어야 할까?"
  * *대상 제품군*:
    1. **올리고 히알루론산 딥 토너** (속건조 해결, 저분자 흡수력, 물토너 제형)
    2. **그린 플라보노이드 2.5 패드** (민감성 트러블 진정, 붉은기 완화, 비건 쿨링)
    3. **올리고 히알루론산 워터리 스킨 마스크** (급속 수분 충전, 밀착 시트, 쿨링 진정)

---

## 3. 핵심 가치 제안 (Value Proposition)
1. **진짜 바이럴 메가 쇼츠만 엄선 (Zero-Noise)**:
   * 조회수 최소 5만 회 이상, 평균 수십만~수백만 회의 검증된 한국 뷰티 쇼츠만 추출.
2. **5초 스캔 비주얼 위계**:
   * 시장 인사이트 → 트렌드 카드(도트 게이지, 타깃) → 근거 영상 1:1 직결 임베드 → 골든픽 하이라이트.
3. **인하우스 맞춤 4단 숏폼 콘티 즉시 생성**:
   * `[첫 3초 훅(대사/행동) → 연출 구도(비포/애프터) → 브랜드 소구점 접목 → CTA]` 스토리보드 제공.
4. **100% 무결점 환각 제로 검증**:
   * 실제 존재하는 유튜브 영상 ID만 인용하며, 클릭 즉시 원본 영상으로 연결.

---

## 4. 데이터 파이프라인 명세
* **데이터 소스**: YouTube Data API v3
* **카테고리 타겟팅**: `videoCategoryId = 26` (Howto & Style) + K-뷰티 핵심 메가 앵커 키워드
* **기간 필터링**: 최근 N일(1~10일, 기본 7일) 업로드 (`publishedAfter` RFC3339 UTC)
* **조회수 임계치(Threshold)**:
  * 1차 후보군 수집 후 60초 이하 Shorts 우선 + 조회수 상위 정렬
  * 한글 2자 이상 포함 후처리 필터 적용
* **캐싱 정책**: `diskcache`를 통해 동일 조건 12시간 캐시 히트 (API 쿼터 절약)

---

## 5. 성공 지표 (PMF Acceptance Criteria)
1. **평균 조회수**: 추천 영상 평균 10만 회 이상 (1,000회 수준 저유입 영상 0건)
2. **환각률**: 가짜 ID 인용률 0% (실존 URL 100% 일치)
3. **콘티 유효성**: 더랩바이블랑두 3개 제품별 특화된 숏폼 훅 및 연출 구도 100% 도출
4. **접근 편의성**: 파일 더블클릭 즉시 구동(HTML) + 링크 배포(Streamlit) 듀얼 제공
