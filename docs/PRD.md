# 📄 PRD v2: K-Beauty TrendSetter Pro (B2B Edition)

> **미션**: 화장품 브랜드사 인하우스 마케터가 매일 1~2시간씩 유튜브 쇼츠를 뒤지는 스크린타임을 **10분 이내**로 줄여주고, 팀장 결재와 인플루언서 전달까지 업무를 대신해 주어 **법인카드로 구독료를 내고 고용하고 싶은 B2B 제품**을 만든다.

---

## 1. 배경 및 고객 문제 (Jobs-to-be-Done)
- **고객**: K-뷰티 화장품 브랜드사 인하우스 마케터 (초기 검증 페르소나: 더랩바이블랑두 담당자).
- **고통**: 매일 어떤 쇼츠가 뜨는지 파악하고, 우리 제품에 어떻게 녹일지 분석하느라 스크린타임만 쌓이고 정작 캠페인 실행 시간을 빼앗김.
- **고객이 우리 제품을 고용하는 이유 (Hire Criteria)**:
  1. 내가 유튜브를 따로 켜서 뒤지지 않아도 지금 진짜 뜨는 K-뷰티 쇼츠가 깨끗하게 클리핑되어 있다.
  2. 여러 영상을 관통하는 이번 주 바이럴 포맷·인사이트를 한눈에 파악한다.
  3. 우리 제품과 결이 맞는 컨셉(Go)과 억지로 엮으면 욕먹는 컨셉(Drop)을 냉정하게 걸러준다.
  4. 바로 복사해서 팀장 보고와 인플루언서 DM에 쓸 수 있는 캠페인 안이 나온다.

---

## 2. 기능 우선순위 (P0 → P3)

### P0. 인기 K-뷰티 쇼츠 자동 클리핑 (YouTube Data API v3)
- 설정 기간(7/14/30일 실측 후 최적 기본값 확정) 내 한국 뷰티 쇼츠 수집.
- **바이럴 지표 3종 계산**:
  - 총 조회수 (`views`)
  - 일평균 조회수 (`views_per_day = views / max(1, days_since_published)`) — 급상승 영상 포착
  - 좋아요 반응률 (`like_rate = likes / views * 100`)
- 저유입 노이즈 차단 + 한국어 필터 + `youtube_transcript_api` 자막 수집(없으면 `text_source="meta"` 명시).

### P1. 편향 없는 시장 팩트 & 트렌드 인사이트 도출 (Step 1)
- **브랜드 정보 완전 차단** 상태에서 영상별 실제 행동, 등장 제품군, **영상 포맷 태그**(예: `비포/애프터 실험형`, `올영 추천 리스트형`, `응급처치 루틴형`, `믹싱 꿀팁형`, `겟레디윗미`)와 **자막 원문 인용** 추출.
- 클리핑된 영상 전체를 관통하는 **시장 인사이트 패턴 2~3개** 요약.

### P2. 냉정한 브랜드 컨셉 매칭 — Go / Pivot / Drop (Step 2)
- `products.json`(출처 검증된 제품 문구)과 Step 1 팩트를 1:1 대조.
- **Go (4~5점)**: 포맷·행동이 제품 확인 문구와 직접 연결 → 캠페인 기획 진행.
- **Pivot (3점)**: 일부 연결 → 서브 테스트 수준.
- **Drop (1~2점)**: 영역 불일치(예: 색조 믹싱 vs 기초 토너) 또는 억지 연결 → **탈락 사유와 함께 접어서 표시**.

### P3. 제품 녹이기 캠페인 안 & 2종 즉시 복사 산출물 (Step 3 + Step 4 감사)
- **Go 판정 컨셉에만** 생성:
  - 광고 티 안 나게 제품이 들어가는 시점(`product_moment`), 첫 3초 훅(`hook`), 비포 상황(`before`), 구매 CTA(`cta`), 금지 표현 메모(`creator_note`).
- **원클릭 복사 2종**:
  1. `[팀장/슬랙 보고용 1페이지 요약]`
  2. `[인플루언서/대행사 전달용 촬영 가이드]`
- **코드 기반 자동 감사(Step 4)**: 원문 자막 인용 존재 여부, ID 실존 여부, 영역 불일치 강제 Drop, `products.json` 외 금지 문구/미확인 수치 검출.

## 3. B2B 수용 기준 (Acceptance Criteria — QA Auditor 채점표)
1. **억지 연결 차단**: 색조/무관 영상(`jfsweQpxqsY` 포함) Drop 정확도 **≥ 90%**. 전부 Go 판정 시 즉시 FAIL.
2. **날조 인용 0건**: 카드에 표시된 자막 인용이 실제 영상 자막에 100% 존재.
3. **출처 없는 과대광고 0건**: `products.json` 확인 문구 밖의 수치·순위·효능 표현 0건.
4. **업무 대체력(WTP)**: 마케터가 유튜브를 다시 뒤지지 않아도 되고, 2종 브리프를 복사해 바로 쓸 수 있는 구체성 확보.
5. **수집 품질**: 7/14/30일 실측 비교를 통해 저유입을 최소화하고 대세 영상이 잡히는 기간을 데이터로 증명.
