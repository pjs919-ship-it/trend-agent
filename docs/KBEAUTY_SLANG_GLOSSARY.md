# 📖 K-뷰티 숏폼(릴스·쇼츠) 유행어 & 바이럴 표현 사전

> **목적**:  
> 1. AI가 숏폼 제목·자막의 최신 한국어 밈/은어를 오역하지 않도록 학습 기준 제공 (`밤티` 오역 등 방지)  
> 2. 향후 **숏폼레이더 내 '요즘 뜨는 뷰티 숏폼 표현 사전' 콘텐츠(마케터 리텐션·SEO/GEO)**로 활용

---

## 1. 외관 · 퀄리티 · 호불호 밈 (AI 오역 주의 1순위)
| 표현 | 정확한 뜻 | 마케터 활용 / 주의점 |
|---|---|---|
| **밤티** | 못생기고 촌스럽거나 구린 디자인·비주얼·결과물 *(부정 표현)* | 절대 '밤에 좋은'으로 오역 금지! *"밤티 나는 패키지인데 내용물은 찐템"* 같은 반전 훅에 주로 쓰임 |
| **느좋** | '느낌 좋다'의 줄임말. 감성적이고 세련된 무드·패키지·발색 | 감성 릴스·패키지 언박싱 카피에 적합 |
| **추구미** | 내가 추구하는 이상적인 이미지·스타일 (예: 청순 추구미, 쿨톤 추구미) | 타겟별 무드 제안 카피에 활용 |
| **톤그로** | 피부 톤과 전혀 안 어울려 어그로가 끌릴 정도로 뜨는 색조 | 퍼스널컬러 비교·실패 없는 컬러 추천 훅 |
| **테무산** | 품질이 조악하거나 기대 이하인 짝퉁·저퀄 느낌 *(풍자/비교용)* | 저가 유사품 대비 정품 퀄리티 비교 맥락 |
| **찐템 / 내돈내산** | 협찬 없이 직접 사서 진짜 잘 쓰는 검증된 제품 | 신뢰도 강조 (단, 실제 협찬 시 '내돈내산' 허위 표기 금지) |
| **호불호 갈리는 / 똥손** | 취향이 나뉘거나 메이크업 초보도 쉽게 쓸 수 있는지 강조할 때 | *"똥손도 10초 컷"* 같은 초보자 진입장벽 낮추는 훅 |

## 2. 피부 · 제형 · 메이크업 실무 줄임말
| 표현 | 정확한 뜻 | 자주 쓰이는 카테고리 |
|---|---|---|
| **화잘먹** | '화장이 잘 먹는' 피부 상태 (들뜸·밀림 없음) | 토너·패드·수분세럼·마스크팩 |
| **수부지** | 수분 부족형 지성 (겉은 번들거리고 속은 당김) | 저분자 히알루론산 토너·가벼운 수분크림 |
| **닦토 / 흡토 / 스킨팩** | 닦아내는 토너 / 흡수시키는 토너 / 화장솜에 적셔 붙이는 팩 | 토너·패드 |
| **속광 / 쫀광 / 물광** | 피부 속부터 차오르는 촉촉하고 쫀쫀한 광채 | 수분세럼·앰플·글로우 쿠션 |
| **요철·각질 부각** | 모공이나 각질이 화장 후 도드라져 보이는 현상 | 기초 보습·프라이머·쿠션 |
| **다크닝** | 시간이 지나면서 베이스 메이크업이 칙칙하게 어두워지는 현상 | 쿠션·파운데이션·톤업 선크림 |
| **탕후루립 / 글로우립** | 탕후루처럼 맑고 탱글하게 빛나는 광택 립 | 립틴트·립글로스 |

## 3. 숏폼 바이럴 후킹 말투 패턴
- **반전·솔직형**: *"패키지는 밤티인데 효과는 미쳤음"*, *"솔직히 이거 광고 아니고 내돈내산인데..."*
- **손실 회피·경고형**: *"올영 세일 때 이거 모르고 사면 손해"*, *"화장 뜨는 사람들 딱 이것만 바꿔보세요"*
- **댓글 참여·검증형**: *"댓글에 물어보신 그 제품"*, *"성분표 숫자 직접 다 더해봤습니다"*
- **초보자 구원형**: *"똥손도 1분 만에 끝내는 ~"*, *"아침에 시간 없을 때 딱 하나만"*
