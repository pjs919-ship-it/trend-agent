## 1. 서비스 흐름 정책 (한국 KR 전용 2단계)
- **국가 범위**: 대한민국(`regionCode=KR`, `relevanceLanguage=ko`) 전용. 국가 선택 기능은 제공하지 않습니다.
- **1단계 (시장 트렌드 탐색)**: 브랜드 정보를 전혀 넣지 않고, 한국 유튜브 쇼츠 인기 흐름만 객관적으로 먼저 파악합니다. 어느 단계에서든 멈추고 바로 2단계로 넘어갈 수 있습니다.
- **2단계 (우리 제품에 입히기)**: 1단계에서 모아온 영상을 그대로 재사용합니다(**추가 유튜브 API 쿼터 0**). 제품 카테고리·제품명·강조 키워드를 자유롭게 입력해 맞춤 캠페인과 카피를 뽑습니다.
- **초기 화면 정책**: 처음 열었을 때 가짜·예시 결과를 자동으로 띄우지 않고 깨끗한 대기 화면을 유지합니다.

### 2-2. 기간·캐시·필터 기준
- **기간 토글**: `최근 7일 (급상승)` / `최근 30일 (대세, 기본값)` — 7·14·30일 실측 결과 30일이 14일 대비 조회수 중앙값 23배(27,581회 vs 1,182회)로 기본값 확정.
- **당일 캐시**: 같은 날 이미 조회한 경로·기간은 캐시(파이썬 `cache_store` / 브라우저 캐시)에서 즉시 불러와 **추가 유튜브 쿼터 0유닛**.
- **쇼츠 길이 기준**: `전체` 180초 이하 / 뷰티 세부 검색 120초 이하.
- **스팸·낚시 제거**: 조회수 0건, 제목 해시태그 8개 이상 도배, 스팸 문구(`무료나눔`, `이벤트 참여`, `쿠팡파트너스 링크`, `구독 좋아요 알람`) 제외.
- **한글 필터**: 제목+설명에 한글 2자 이상 포함된 한국어 영상 우선(3건 미만일 때만 폴백).

## 3. 정렬 로직 및 바이럴 신뢰도 벤치마크 등급

### 3-1. 정렬 기준
- **🔥 빠르게 뜨는 순 (기본)**: `(하루 평균 조회수 × 0.6) + (총 조회수 × 0.4)` 내림차순. *(하루 평균 = 총 조회수 ÷ 업로드 경과일, 최소 0.25일=6시간)*
- **👀 총 조회수 순**: `viewCount` 내림차순.
- **❤️ 좋아요율 순**: `(likeCount ÷ viewCount) × 100` 내림차순.
- **참고 (공유 수 불가)**: YouTube 공개 API는 타인 영상의 공유 수(`shareCount`)를 제공하지 않습니다. 대신 보조 반응 지표로 **댓글율(`commentCount ÷ viewCount × 100`)**을 함께 표시합니다.

### 3-2. 한국 쇼츠 바이럴 벤치마크 등급 (S / A / B / C)
| 등급 | 기준 (둘 중 하나 충족) | 마케터 해석 |
|---|---|---|
| **🔥 S등급 · 메가 바이럴** | 총 조회수 **10만 회↑** 또는 하루 평균 **1만 회↑** | 검증된 대세 — 즉시 벤치마킹 권장 |
| **⚡ A등급 · 급상승** | 총 조회수 **3만~10만 회** 또는 하루 평균 **3,000~1만 회** | 지금 치고 올라오는 중 — 마켓 타이밍 적합 |
| **📈 B등급 · 초기 반응** | 총 조회수 **1만~3만 회** 또는 하루 평균 **1,000~3,000회** | 초기·니치 트렌드 — 추이 관찰 |
| **🔍 C등급 · 저유입 참고** | 총 조회수 **1만 회 미만** | 아직 대중적 대세 아님 — 참고용 |

## 4. 인사이트·매칭·법무 감사 정책

### 4-1. 1단계 트렌드 인사이트 작성 규칙
- 단순 단어·명사구 나열 금지(`"올리브영 추천템"`, `"메이크업 꿀팁"` 등).
- 각 인사이트는 반드시 **`[연출/포맷] + [시청자 심리·고민] + [조회수/반응 근거]`** 3요소를 담은 **45자 이상 완성 문장**으로 3줄 작성.

### 4-2. 2단계 추천(Go) / 보류(Pivot) / 제외(Drop) 판정 규칙
- **양방향 영역 일치 필수**: 기초 제품에 색조 영상이 걸리거나, 색조 제품에 기초 영상이 걸리면 **무조건 제외(Drop, 1점)**.
- **자막 미확인 가드**: 자막을 읽지 못한 영상(제목·설명만 확인)은 최대 **보류(Pivot, 3점)**까지만 허용하며, 직접 시청 필요 안내를 표시.
- **부적합 키워드 차단**: 제품별 `non_fit_territory` 복합어(예: `각질 제거`, `필링`, `스크럽`, `미백`) 충돌 시 강제 제외(Drop). *(단, `"각질 부각"` 같은 보습 고민 표현은 오탐 방지)*
- **추천(Go) 산출물**: 캠페인 방향 + **바로 쓸 카피 3종** + **4단 촬영 콘티**(첫 3초 훅 / 비포 / 제품 등장 / 구매 유도) + 복사 2종(팀장 보고 / 인플루언서 DM) + 1페이지 결재 HTML 보고서 저장.

### 4-3. 화장품법 제13조 및 과대광고 자동 감사
- **절대 금지어 (무조건 차단)**: `완치`, `여드름 완치`, `아토피`, `피부염`, `치료`, `피부과 치료`, `염증 완화`, `피부과 시술`, `기적` — 제품 설명에 넣더라도 저장 시 격리·거부되며 콘티·카피에서 무조건 위반 적발.
- **과대광고·미확인 수치**: `1위/1등`, `즉각 진정`, `1초 컷`, `24시간 지속`, `10배 흡수`, `100%`, `모공 축소`, `주름 개선`, `미백` 등 확인된 문구에 없는 표현 자동 적발. *(단, `"첫 3초"`, `"5초 컷"` 같은 촬영 연출 시간 표현은 허용)*
- **위반 시 동작**: 해당 카드에 빨간 **`🚨 발송 보류 — 검수 필요`** 배너 표시 및 DM 복사 시 재확인 팝업.

## 5. API 예산·보안·로그 정책
- **YouTube 일일 예산 가드**: 파이썬 백엔드 누적 **1,500유닛/일** 상한 (`qa/usage_log.json` 기록, 초과 시 호출 차단).
- **Gemini 모델 정책**: 무료 티어 모델(`gemini-2.5-flash-lite`, `gemini-flash-latest`)만 사용.
- **API 키 보안**: `.env` 및 HTML 자동 연결용 `local_keys.js`는 `.gitignore`로 Git 업로드 영구 차단. 외부 공유용 1페이지 HTML 보고서에도 API 키·`<script>` 0건 보장.
- **디버그 로그**: HTML 화면 하단 `🧾 수집·분석 상세 로그 보기`에서 API 원본 건수·필터 탈락 건수·AI 응답 시간을 실시간 확인 및 복사 가능.
