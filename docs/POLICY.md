## 1. 서비스 흐름 정책 (한국 K-뷰티 전용 2단계)
- **서비스명**: `숏폼레이더 (ShortformRadar)` — K-뷰티 마케터를 위한 유튜브 쇼츠 트렌드 분석 & 캠페인 기획 도구.
- **국가 범위**: 대한민국(`regionCode=KR`, `relevanceLanguage=ko`) 전용. 국가 선택 기능은 제공하지 않습니다.
- **1단계 (뷰티 트렌드 탐색)**: 홍보할 상품 정보를 넣지 않고, 한국 K-뷰티 유튜브 쇼츠 인기 흐름만 객관적으로 먼저 파악합니다.
- **2단계 (홍보할 상품에 입히기)**: 1단계에서 모아온 영상을 그대로 재사용합니다(**추가 유튜브 API 검색 없음**). 상품 카테고리·홍보할 상품명·핵심 특징을 자유롭게 입력해 맞춤 캠페인과 카피를 뽑습니다.
- **초기 화면 정책**: 처음 열었을 때 가짜·예시 결과를 자동으로 띄우지 않고 깨끗한 대기 화면을 유지합니다.

## 2. 1단계 수집·필터·캐시 정책

### 2-1. 한국 뷰티 계층 경로 (총 16개)
- 비뷰티 노이즈가 심한 `전체(mostPopular)` 경로를 제거하고 **`뷰티 전체`를 최상위 루트**로 집중합니다.
- **계층 구조**:
  - 0단계: `뷰티 전체` (`올리브영 추천템`, `화장품 추천`, `뷰티 꿀템`)
  - 1단계: `기초 스킨케어` / `색조 메이크업` / `헤어·바디`
  - 2단계: 기초 6종(`토너·패드`, `세럼·앰플`, `크림·로션`, `선크림`, `마스크팩`, `클렌징`) · 색조 4종(`립·틴트`, `블러셔`, `쿠션·파데`, `아이메이크업`) · 헤어·바디 2종(`샴푸·트리트먼트`, `바디케어`)
- **채널 구독자 수 배치 조회**: `channels.list(part=statistics, id=...)` 1회 호출(최대 50채널, 1유닛)로 `구독자 대비 N배` 확산력 지표를 계산합니다.

### 2-2. 기간·캐시·배치·필터 기준
- **일일 배치 스냅샷 (GitHub Actions)**: 매일 **오전 08:00 KST(`최근 30일`)** 및 **오후 17:00 KST(`최근 7일`, 유튜브 쿼터 초기화 직후)** 자동 실행(`batch_update.py`)해 `data/trends_snapshot.json`, `data/trends_snapshot.js`, `beauty_channels.json`을 갱신합니다. **1일(오늘 급상승)** 데이터도 함께 자동 생성됩니다.
- **기간 토글**: **`⚡ 1일 (오늘 급상승)`** / **`🔥 7일 (이번 주)`** / **`🏆 30일 (대세, 기본값)`**
- **비뷰티 노이즈 차단**: AI가 `기타/뷰티무관`으로 분류한 영상 및 비뷰티 낚시 키워드(`알바 공감` 등)는 스냅샷 저장 전 자동 제외합니다.
- **당일 캐시**: 같은 날 이미 조회한 경로·기간은 캐시(파이썬 `cache_store` / 브라우저 캐시)에서 즉시 불러와 추가 유튜브 쿼터를 쓰지 않습니다.
- **쇼츠 길이 기준**: **180초(3분) 이하** (유튜브 공식 쇼츠 최대 길이 기준), `search.list`는 `maxResults=50` + `order=viewCount` 사용(`videoCategoryId=26` 및 `" shorts"` 접미사 강제 제거).
- **스팸·낚시 제거**: 조회수 0건, 제목 해시태그 8개 이상 도배, 스팸 문구 제외.
- **한글·중복 필터**: 해시태그를 제외한 본문에서 완성형 한글 4자 이상(또는 제목+설명 6자 이상)만 통과 + 동일 제목 중복 재업로드 제거.

## 3. 마케터 핵심 지표, 정렬 로직 및 바이럴 등급

### 3-1. 카드 핵심 지표 (퍼센트 소수점 제거)
1. **👀 조회수**: `39.2만` 등 읽기 쉬운 한국어 단위
2. **🔥 하루 평균**: `총 조회수 ÷ 업로드 경과일` (최소 0.25일)
3. **📈 평소 대비 N배**: `총 조회수 ÷ 채널 평균 조회수(총조회수÷총영상수)` — 기획·소재빨 지표
4. **👥 구독자 대비 N배**: `총 조회수 ÷ 채널 구독자 수` — 작은 채널 알고리즘 확산 지표
5. **🏷️ 광고/오가닉 배지**: `paidProductPlacementDetails.hasPaidProductPlacement` 기반 `유료광고` vs `오가닉` 구분
6. **📅 게시일 · ❤️ 좋아요 · 💬 댓글 N개 · ⬆️ 이전보다 +N**

### 3-2. 정렬 기준
- **🏆 등급·인기 순 (기본)**: 등급(`S>A>B>C`) → 누적 조회수 → 좋아요 수 → 댓글 수.
- **📈 평소 대비 순**: `views_vs_channel_avg` 내림차순.
- **👥 구독자 대비 순**: 조회수 1만 이상이면서 `views_per_subscriber`가 높은 영상 우선.
- **🔥 하루 평균 순**: `views_per_day` 내림차순.
- **👀 조회수 순**: `viewCount` 내림차순.
- **💬 댓글 많은 순**: `commentCount` 내림차순.

## 4. 인사이트·매칭·법무 감사 정책

### 4-1. 1단계 트렌드 인사이트 작성 규칙
- 단순 단어·명사구 나열 금지(`"올리브영 추천템"`, `"메이크업 꿀팁"` 등).
- 각 인사이트는 반드시 **`[연출/포맷] + [시청자 심리·고민] + [조회수/반응 근거]`** 3요소를 담은 **45자 이상 완성 문장**으로 3줄 작성.

### 4-2. 2단계 추천(Go) / 보류(Pivot) / 제외(Drop) 판정 규칙
- **양방향 영역 일치 필수**: 기초 제품에 색조 영상이 걸리거나, 색조 제품에 기초 영상이 걸리면 **무조건 제외(Drop, 1점)**.
- **자막 미확인 가드**: 자막을 읽지 못한 영상(제목·설명만 확인)은 최대 **보류(Pivot, 3점)**까지만 허용하며, 직접 시청 필요 안내를 표시.
- **부적합 키워드 차단**: 제품별 `non_fit_territory` 복합어(예: `각질 제거`, `필링`, `스크럽`, `미백`) 충돌 시 강제 제외(Drop). *(단, `"각질 부각"` 같은 보습 고민 표현은 오탐 방지)*
- **추천(Go) 산출물**: 캠페인 방향 + **바로 쓸 카피 3종** + **4단 촬영 콘티**(첫 3초 훅 / 비포 / 제품 등장 / 구매 유도) + 복사 2종(팀장 보고 / 인플루언서 DM) + 1페이지 결재 HTML 보고서 저장.

### 4-3. 화장품법 제13조 및 과대광고 자동 감사
- **절대 금지어 (무조건 차단)**: `완치`, `여드름 완치`, `아토피`, `피부염`, `치료`, `피부과 치료`, `염증 완화`, `피부과 시술`, `기적` — 제품 설명에 넣더라도 저장 시 격리·거부되며 콘티·카피에서 무조건 위반 적발.
- **과대광고·미확인 수치**: `1위/1등`, `즉각 진정`, `1초 컷`, `24시간 지속`, `10배 흡수`, `100%`, `모공 축소`, `주름 개선`, `미백` 등 확인된 문구에 없는 표현 자동 적발. *(단, `"첫 3초"`, `"5초 컷"` 같은 촬영 연출 시간 표현은 허용)*
- **위반 시 동작**: 해당 카드에 빨간 **`🚨 발송 보류 — 검수 필요`** 배너 표시 및 DM 복사 시 재확인 팝업.
