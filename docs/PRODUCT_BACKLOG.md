> **목적**: K-뷰티 인하우스 마케터의 데일리 리텐션 확보 및 유료 전환(시딩·기획)을 위한 기능 백로그 및 사업 기회 관리 문서

## 1. 타겟 고객 & 수익화(Freemium) 전략

- **핵심 타겟**: 연 매출 10억~200억대 인디·중소 K-뷰티 브랜드의 **1인 다역 인하우스 마케터** (자사 숏폼 기획 + 인플루언서 시딩을 혼자 또는 소수 인원이 겸임)
- **수익화 구조 (무료 습관화 → 유료 전환)**:
  - **무료 (리텐션 엔진 — 데일리 브리핑)**: 매일 출근 직후 3분 만에 보는 `1일 / 7일 / 30일` K-뷰티 쇼츠 트렌드, 핵심 포맷 요약, 광고/오가닉 구분 배지 → *매일 방문 습관 및 마케터 커뮤니티 입소문 확보*
  - **유료 (수익화 엔진 — 시딩 & 맞춤 기획)**: `구독자 1~10만 가성비 시딩 후보 자동 추출`, `채널 평소 대비 터짐 배수`, `댓글 구매문의 지수 & VOC 요약`, `우리 제품 맞춤 카피·콘티·시딩 DM 생성` → *매주 5~10시간의 섭외 노가다 절감 및 협찬 ROI 방어*

## 2. YouTube Data API v3 전수조사 (수집·지표 가능 목록)

### A. 추가 한도 **0유닛** (기존 `videos.list` / `channels.list` 응답 확장)
| API 필드 | 추출 데이터 | 서비스 활용 |
|---|---|---|
| `videos` → `paidProductPlacementDetails.hasPaidProductPlacement` | 유료 광고/협찬 여부 | **광고(협찬) vs 오가닉(내돈내산) 배지** 및 향후 탭 분리 |
| `videos` → `snippet.tags`, `topicDetails` | 크리에이터 태그, 주제 분류 | 급상승 해시태그 클러스터링, 비뷰티 노이즈 차단 |
| `videos` → `contentDetails.caption` | 공식 자막 트랙 보유 여부 | 자막 있는 영상 우선 분석 표시 |
| `channels` → `statistics.viewCount`, `videoCount` | 채널 누적 조회수, 총 영상 수 | **평소 평균(`총조회수 ÷ 총영상수`) 대비 '이번 영상 터짐 배수'** 계산 |
| `channels` → `snippet.customUrl`, `country` | 채널 `@핸들`, 국가(`KR`) | 한국 채널 정확도 향상 + 시딩용 `@핸들` 제공 |

### B. **1유닛** 초저비용 API (`search.list` 100유닛 대비 100배 효율)
| API | 비용 | 서비스 활용 |
|---|---|---|
| `playlistItems.list` (채널 `uploads` ID) | **1유닛** / 50영상 | `beauty_channels.json`에 등록된 핵심 K-뷰티 채널 최신 쇼츠 전수 수집 (토너·세럼 누락 해결) |
| `commentThreads.list` | **1유닛** / 영상 1개 | 상위 댓글 20~50개 수집 → **구매문의 지수(`🛒`)**, **소비자 VOC 요약**, 언급 브랜드 추출 |

### C. API 제약 사항 (수집 불가)
- `공유 수(shareCount)`, `평균 시청 지속 시간/이탈률`, `시청자 인구통계` → 유튜브 크리에이터 본인 스튜디오 비공개 지표
- `captions.download` → OAuth 인증 필요 (현재처럼 `youtube_transcript_api` 유지)
- `relatedToVideoId` → YouTube API 지원 종료

## 3. 기능 백로그 (우선순위별)

### P0 — 1단계: 데일리 브리핑 완성도·수집 순도 혁신 (무료 핵심)
1. **`1일 / 7일 / 30일` 조회 기준 신설**: 24~48시간 급상승 + 전일 대비 `views_delta` 기반 데일리 브리핑
2. **비뷰티 노이즈(`기타/뷰티무관`) 자동 제거**: 스냅샷 저장 전 필터링으로 뷰티 순도 100% 확보
3. **검색 키워드 고도화 + `beauty_channels.json` 핵심 채널 풀 병행**: `search.list` 누락(`토너·패드` 등) 보완
4. **`광고/오가닉` 배지 추가**: `hasPaidProductPlacement` 기반 표시 (향후 탭 분리 지원)
5. **지표 명확화**: `📈 평소 대비 N배` (소재빨) vs `👥 구독자 대비 N배` (알고리즘 확산) 쉬운 한 줄 설명 제공
6. **TDS(토스 디자인 시스템) 기반 UI/UX 개편**: 한 화면 한 목적 (`Top` → `ListHeader` → `ListRow` → `BottomCTA`), API 설정 숨김, 위계 정립

### P1 — 2단계: 유료 전환 핵심 (시딩 & VOC 인텔리전스)
1. **황금 시딩 후보 필터**: 구독자 1~10만 + 최근 7일 평소 대비 배수 높음 + 협찬 경험 여부 + `@핸들` 및 맞춤 DM
2. **댓글 VOC 분석 (`commentThreads.list`)**: `🛒 구매·제품 문의 비율` 및 시청자 핵심 질문 3줄 요약 → 상세페이지/카피 소재 연결
3. **광고 vs 오가닉 탭 분리**: 경쟁사 유료 시딩 동향 전용 뷰
4. **K-뷰티 숏폼 유행어·바이럴 말투 사전 콘텐츠화** (`docs/KBEAUTY_SLANG_GLOSSARY.md`): 마케터 리텐션·SEO/GEO 유입용 무료 콘텐츠 탭 + AI 오역 방지(`밤티`, `느좋`, `추구미`, `톤그로` 등) 상시 반영
5. **유저 의견·키워드 요청 수집 플로우 (외부 배포 시 필수 구현)**: 스냅샷 내 검색 결과 부족 시 실시간 API 호출 없이 요청 키워드 적립(`"다음 트렌드 수집에 반영할게요"`), 화면 내 초간단 의견 접수 창구를 두어 실제 마케터 니즈 기반 마켓핏(PMF) 개선에 활용
6. **브랜드 말투 커스텀 & 채널별 복붙 카드 확장 (Cycle #3 실무 피드백)**:
   - 2단계 입력에 **`우리 브랜드 말투 예시 1~2줄(선택)`** 추가 → 특유의 어미·줄바꿈·이모지 리듬(`.. !`, `.. ♡` 등)을 대본·DM·카피에 자동 반영
   - 출력 포맷에 **`인스타 스토리/릴스 연계 시퀀스 카드`**(카드별 1클릭 복사) 및 **`영상 AI 제작용 프롬프트 복사`** 추가

### P2 — 3단계: 신규 사업/서비스 확장 기회
1. **경쟁 브랜드 유료 시딩 레이더**: 특정 경쟁사/키워드의 주간 협찬 집행 빈도 및 소구점 리포트
2. **올리브영/다이소 랭킹 × 쇼츠 바이럴 교차 대시보드**: 유통 채널 인기 템의 숏폼 확산 선행 지표화
3. **팀 협업 워크스페이스**: 브랜드별 제품 DB 클라우드 저장, 시딩 컨택 상태 관리(CRM)
4. **북미 틱톡샵·아마존 K-뷰티 인디 브랜드 트랙 (Cycle #3 피드백)**: 영문 틱톡샵·릴스 문법 기반 훅/스크립트 생성 및 US 뷰티 트렌드 수집 확장

## 4. 외부 배포 · 그로스 측정 & SEO 로드맵

> **선행 조건**: **최종 서비스명 + 신뢰 제목(예: `올리브영 출신 PM이 만든...`) 확정 후** 아래 Phase 1을 일괄 반영한다.

### Phase 1 — 유저 테스트 · 지인/SNS 배포 패키지 (Vercel + 무료 측정 4종)
- **호스팅 구조**: **Vercel**(정적 화면 + 2단계 AI 키 숨김 서버리스 `/api/plan`) + **GitHub Actions**(1단계 트렌드 수집 유지, 크론 누락 시 Vercel/외부 트리거 보완)
- **4단 데이터 파이프라인 (DB 없이 구축)**:
  1. **UTM 링크 분리**: `kakao` / `linkedin` / `threads` 등 채널별 유입·전환 비교
  2. **GA4 핵심 5이벤트**: `view_landing` → `explore_filter` → `open_step2` → `generate_step2`(카테고리·타겟 포함) → `copy_step2_output`(핵심 전환 지표)
  3. **Microsoft Clarity**: 이탈 구간 세션 녹화·히트맵으로 UX 막힘 지점 확인
  4. **Google Sheets 정성 피드백**: 2단계 결과 직후 `👍 / 💬` 버튼 + 헤더 `의견 남기기` (유입 UTM·카테고리·한 줄 이유 시트 누적 → `docs/USER_FEEDBACK.md` 관리)
- **공유 & 검색 기본**: 카톡/SNS용 OG 태그(`og:title`, `og:description`, `og:image`) + Google Search Console 등록 + `robots.txt` / `sitemap.xml` / `canonical` 기본 설정

### Phase 2 — PMF 확인 후 오가닉 유입 확장 (본격 SEO / GEO)
- **카테고리별 정적 HTML 자동 생성 (pSEO)**: 배치 실행 시 `/trends/...` 정적 브리핑 페이지를 함께 생성해 검색·AI 봇 크롤링 대응
- **콘텐츠 SEO/GEO**: `docs/KBEAUTY_SLANG_GLOSSARY.md` 기반 K-뷰티 숏폼 용어집 공개 + JSON-LD(`SoftwareApplication`/`Article`) 및 `/llms.txt` 추가
- **DB 도입 시점**: 로그인·내 제품 저장·시딩 CRM이 들어가는 유료화 직전에 Supabase 등으로 일괄 전환
