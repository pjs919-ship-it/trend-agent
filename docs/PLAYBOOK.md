# PLAYBOOK — 작업 방식 개선 기록

> 규칙: 매 루프 끝에 [틀린 가정 / 증거 / 고친 방법 / 다음 규칙]을 기록한다. 다음 루프 시작 전에 이 문서를 먼저 읽는다.

## 상시 규칙 (누적)
1. 기능이 돌아가는 것과 고객 문제가 풀린 것은 다르다. 결과 화면을 직접 읽고 마케터 입장에서 판단하기 전에는 완료라고 하지 않는다.
2. 제품·사실 정보는 출처 없이 쓰지 않는다. 출처 도메인과 확인 수준(confidence)을 같이 기록한다.
3. 브랜드 정보를 넣은 프롬프트에서 시장 트렌드를 뽑지 않는다. 팩트 추출과 브랜드 판정을 분리한다.
4. 모든 것에 높은 점수를 주는 결과는 실패로 본다. Drop 케이스가 통과해야 QA 통과.
5. 계획을 문서로 옮길 때 사용자가 승인한 내용을 요약하지 않고 그대로 보존한다.
6. 07:00 전에는 종료 선언을 하지 않는다. 기준 미달이면 미달로 보고한다.

## Loop 0 — 제품 진실 확보 (2026-11-25 01:30)
- 틀린 가정: 제품 문구를 그럴듯하게 써도 된다고 생각했다. 사용자가 준 URL을 읽지 않았다.
- 증거: 검색으로 확인한 결과 "7스킨", "올리브영 1위", "2.5mm 보습", "3중 레이어 거즈"는 근거를 찾지 못했다. 패드의 '2.5'는 이오시딘 2.5% 함유를 뜻한다.
- 고친 방법: `products.json`에 확인된 문구만 남기고 출처 도메인과 confidence=medium을 기록. 근거 없는 문구는 `unverified_removed_from_v1`로 분리.
- 한계: 공식 페이지 원문이 아니라 검색 요약 기반이다. 임상 수치(111.25%)는 시험 조건 확인 전에는 광고 문구로 쓰지 않는다.
- 다음 규칙: 코드의 제품 프리셋은 `products.json`에서만 읽는다. 하드코딩 금지.

## Sprint 1 — B2B 파이프라인 1차 구현 및 독립 QA (2026-11-25 01:55) — 판정: FAIL (반려)
- 틀린 가정:
  1. "금지 문구 리스트와 정규식 몇 개로 과대광고를 다 막을 수 있다"고 생각했다.
  2. "서브에이전트에서 `py_compile`도 unsandboxed로 돌릴 수 있다"고 가정해 60초 권한 타임아웃을 발생시켰다.
- 증거 (`docs/QA_REPORT.md`):
  1. `_brief_violations`가 `creator_note`의 주의사항을 위반으로 오탐(3건)하면서, `"올리브영 1등 / 3초 만에 즉각 진정 / 24시간 / 10배"`는 위반 0건으로 통과시켰다.
  2. `KBEAUTY_MEGA_KEYWORDS[:4][:3]` 이중 슬라이싱으로 기초 핵심 키워드 5개가 죽은 코드가 되었고 쿼터 33%를 색조에 낭비했다.
  3. 자막 없는 영상(`text_source="meta"`)이 Go 및 촬영 가이드까지 무경고 통과했고, `linked_claim`은 `"토너"` 2글자만 넣어도 통과했다.
  4. `creator_guide_md`에 개발자 파일명(`products.json`)이 노출되었다.
- 고친 방법 (Sprint 2 반려 지시):
  - QA 결함 6건을 P0로 즉시 반려하고, 오프라인 골든셋 15개(`cache_store` 14건 + `jfsweQpxqsY`) + 단위 테스트로 모든 규칙·감사·과대광고 검출을 100% 자동 검증한다.
- 성과 극대화 아이디어 (백로그 반영):
  - `creator_guide_md`는 인플루언서에게 그대로 DM/메일 복붙할 수 있도록 개발자 용어 0% + 화장품법 금지 표현 체크리스트 + 참고 영상 링크/타임스탬프를 완비한다.
- 다음 규칙:
  - 모든 서브에이전트는 네트워크가 필요 없는 `py_compile`/로컬 단위 테스트를 반드시 샌드박스(`BypassSandbox=false`)에서 실행한다.
  - QA Auditor가 FAIL을 내린 항목은 단위 테스트로 재현→수정→통과를 증명하기 전에는 절대 다음 단계로 넘어가지 않는다.

## Sprint 2 — QA 6대 결함 수정 및 레드팀 재검수 (2026-11-25 02:06) — 판정: FAIL (레드팀 3건 추가 적발)
- 틀린 가정:
  1. "6대 결함을 단위 테스트로 통과시켰으니 복사 산출물도 바로 DM 발송 가능할 것이다"라고 가정했다.
  2. "단일어 `각질`을 금지 키워드로 막으면 안전할 것이다", "`3초` 같은 시간 숫자를 일괄 차단하면 과대광고를 막을 수 있을 것이다"라고 단순하게 가정했다.
- 증거 (`docs/QA_REPORT.md` Sprint 2):
  1. `creator_guide_md` 본문에 `(kurly, glowpick 요약)` 등 내부 출처 괄호가 그대로 노출되어 인플루언서 DM 복붙 불가.
  2. 스키마가 요구하는 `"첫 3초: ..."` 문구가 `3초` 수치 위반으로 자기 오탐(RT1)되고, 반대로 `"여드름 완치"`, `"아토피 피부염"`, `"주름 개선"`, `"미백 효과"`, `"모공 축소"`는 0건 미탐(RT2).
  3. 자막 `[음악]` 태그 삽입 시 정상 인용 탈락(RT3), `"각질 부각될 때 패드로 5분 팩"` 정상 Go 영상이 단일어 `"각질"` 때문에 강제 Drop(RT4).
- 고친 방법:
  - `creator_guide_md`에서 내부 출처 괄호 자동 스트립 + `[마케터 내부 확인용 — 발송 전 삭제]` / `[인플루언서 전달 본문]` 2단 분리.
  - 촬영 연출 시간(`첫 3초`, `N초 컷`, `5~10분 팩`)과 효능 과장 시간(`3초 만에 진정`, `24시간 지속`)을 문맥 정규식으로 분리 + 화장품법 제13조 의약품/기능성 오인 표현 리스트 보강.
  - 자막 정규화 시 `[음악]/[박수]` 등 비음성 태그 제거 + `각질 제거/필링/스크럽/AHA/BHA` 복합어로 정밀화.
- 성과 극대화 아이디어 (백로그 반영):
  - UI에서도 `[내부 보고 복사]`와 `[크리에이터 DM 복사]` 버튼을 분리하고, 크리에이터 복사본에는 내부 경고/출처가 1글자도 섞이지 않게 보장한다.
- 다음 규칙:
  - 모든 복사 산출물은 코드가 아니라 **실제 출력 문자열 전문을 사람이 읽듯 검수**한다.
  - 금지 키워드는 단일 명사 대신 행위/효능 복합어와 문맥으로 설계해 정상 Go 영상 오탐을 막는다.
