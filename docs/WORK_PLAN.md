# WORK PLAN — 01:30 ~ 07:00 (v2: 업무 프로세스 기반 재설계)

## 0. 정직한 현황 진단
- v1.0의 "PMF 100점"은 파일 존재·조회수 같은 껍데기 지표였고, 영상 내용과 카드 내용의 일치는 검증하지 않았다. 무효 처리한다.
- 더랩바이블랑두 제품 정보(7스킨, 올리브영 1위, 2.5mm 보습 등)는 사용자가 준 URL을 읽고 가져온 것이 아니다. 출처 없는 문구다. Loop 0에서 실제 출처로 교체하고, 읽지 못하면 "미확인"으로 표시한다.
- 영상 자막 없이 제목만 보고 LLM이 브랜드 문구를 복사해 트렌드를 날조했다.
- 기간을 7일로 좁힌 탓에 최고 조회수가 15만 수준이었다. 기간은 감이 아니라 실측으로 정한다.

## 1. 마케터 업무 프로세스 (제품의 뼈대)
(아래 예시의 트렌드명·제품 문구는 설명용이다. 실제 제품 문구는 Loop 0에서 출처 확인 후 사용한다.)

### Step 1. 시장 펄스 감지 — 편향 없는 팩트 수집
- 마케터의 생각: "내가 토너를 담당한다고 해서 유튜브 전체가 토너 이야기만 하지는 않는다. 오늘 뷰티 씬에서 대중이 반응한 진짜 팩트가 뭐지?"
- 업무: 브랜드(더랩바이블랑두)를 완전히 배제한 상태에서 오늘 한국 뷰티 쇼츠의 자막과 핵심 행동을 분석해 순수한 시장 트렌드 3~5가지를 추출한다.
- 예: [A: 틴트+쿠션 믹싱 치크] / [B: 환절기 급속 수분 레이어링] / [C: 모공 쿨링 패드팩]

### Step 2. 냉정한 브랜드 적합도 판정 — 탈락의 미학
- 마케터의 생각: "이 트렌드 중 우리 딥 토너/패드로 진짜 침투할 수 있는 건 뭐고, 억지로 엮으면 욕먹는 건 뭐지?"
- 업무: 각 트렌드와 제품 소구점을 1:1로 대조해 3가지 판정을 내린다.
  - Drop (1~2점): 예) A 틴트 믹싱 → 색조 영역. 기초 토너를 들이밀면 조롱당함. 집행 금지.
  - Pivot (3점): 예) C 모공 쿨링 → 패드는 맞지만 모공 전문 라인이 아니므로 서브 테스트만.
  - Go (4~5점): 예) B 급속 수분 레이어링 → 제품 소구점과 일치(소구점은 출처 확인 후). 메인 캠페인 기획 착수.

### Step 3. 바이럴 코드 역기획
- 마케터의 생각: "선택된 영상이 왜 터졌지? 크리에이터가 쓴 첫 3초 장치가 뭐였지?"
- 업무: 채택된 영상의 자막과 연출을 뜯어 [첫 3초 시각 훅 + 공감 대사]를 추출한다. 자막 인용과 타임스탬프를 붙인다.

### Step 4. 인플루언서 브리프 & 숏폼 콘티
- 마케터의 생각: "내일 인플루언서에게 전달할 촬영 가이드와 올영세일 CTA를 문서로 정리하자."
- 업무: 수정 없이 팀장 결재와 크리에이터 DM에 쓸 수 있는 [첫 3초 훅 - 비포 상태 - 제품 침투 - 구매 CTA] 4단 기획안. Go 판정에만 생성한다.
- 핵심 가치: 트렌드 탐색 스크린타임 1~2시간 → 10분 이내.
- 좋은 결과의 정의: "이 영상은 우리와 안 맞다"를 근거와 함께 말해주는 것. 전부 5점인 결과는 실패.

## 2. 에이전트 구성 (무료 Gemini 티어만 사용)
| 단계 | 모델 | 역할 | 규칙 |
|---|---|---|---|
| ① 팩트 추출 | gemini-2.5-flash-lite | 제목·자막·설명에서 실제 행동/제형 추출 | 브랜드 정보 입력 금지. 자막 인용 필수 |
| ② 브랜드 심사 | gemini-2.5-flash-lite | 팩트 vs 제품 3종 대조, Go/Pivot/Drop | 근거 문장 필수, 틴트/색조는 Drop |
| ③ 콘티 | gemini-flash-latest | Go 판정만 4단 콘티 | Pivot/Drop은 생성하지 않음 |
| ④ 감사 | 코드(LLM 아님) + flash-lite | 인용문이 실제 자막에 있는지 문자열 대조, ID 실존, 판정-점수 일관성 | 불일치 시 해당 카드 제거 또는 재생성 1회 |
- 호출은 영상당이 아니라 배치로 묶고, 결과는 캐시. 429 발생 시 백오프, 호출 수 상한을 둔다.

## 3. 루프 (각 루프는 종료 기준을 못 넘으면 다음으로 못 간다)
- **Loop 0 (~02:00) 제품 진실 확보**: 브랜드 페이지 2곳 읽기 시도. 차단되면 우회하지 않고 "미확인"으로 두고 아침에 붙여넣기 요청. `products.json`에 출처 URL과 함께 저장.
- **Loop 1 (~03:00) 파이프라인**: ①~④ 구현, 자막 추출 가능 비율 측정. 자막이 없으면 제목·설명으로 대체하되 "자막 미확인" 라벨과 신뢰도 하향.
- **Loop 2 (~04:00) 골든셋 QA**: 정답 라벨이 붙은 10~15개 영상(틴트 믹싱 영상 `jfsweQpxqsY` = 반드시 Drop 포함)으로 평가. 통과 기준은 Drop 정확도 ≥ 90%, 날조 인용 0건, 전부 Go 판정 금지. 실패 시 프롬프트·구조 수정 후 재측정.
- **Loop 3 (~05:00) 기간·수집 최적화**: 7/14/30일을 같은 조건에서 실측해 조회수 분포, 한국어 비율, 브랜드 관련 영상 수를 비교하고 기본값 결정. 비용 1유닛인 `videos.list chart=mostPopular`(카테고리 26, KR)도 후보로 포함.
- **Loop 4 (~06:00) UI**: 정보 위계를 판정 요약, Go 카드, 근거(자막 인용·영상), 콘티 순으로 재배치. Drop 목록은 접어서 표시. HTML과 Streamlit 동일 적용.
- **Loop 5 (~06:50) 레드팀 + 정리**: 새 키워드·새 제품으로 재시험, 문서·릴리즈 노트·PLAYBOOK 정리, 커밋.
- **세션 종료 점검 (매 루프 마지막, 생략 금지)**:
  1. 고객 문제 해결 확인: 마케터가 10분 안에 "오늘 올라탈 트렌드와 안 맞는 트렌드"를 근거와 함께 결정할 수 있는가? 실제 실행 결과 화면을 직접 읽고 판단한다.
  2. 남은 결함 찾기: 결과를 마케터 입장에서 읽으며 최소 3가지 약점을 적는다. 못 찾으면 더 의심한다.
  3. 성과 극대화 점검: 결재·인플루언서 전달까지 걸리는 시간을 줄일 방법, 수정 없이 쓸 수 있는 산출물 형태, 제품 3종 간 비교 등 추가 가치를 점검하고 다음 루프 백로그에 넣는다.
  4. 결과를 `docs/PLAYBOOK.md`에 기록: 내가 틀린 가정 / 증거 / 고친 방법 / 다음 루프 규칙.
  5. 다음 루프를 새 스프린트로 시작한다. 07:00 전에는 종료 선언을 하지 않고, 기준 미달이면 미달로 보고한다.
- 모든 루프가 기준을 통과하지 못하면 "완료"라고 하지 않고 미달 항목을 그대로 보고한다.
